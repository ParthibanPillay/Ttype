Find your flow in the terminal.

ttype is a focused, Monkeytype-style typing test built for people who feel at home at a prompt. No accounts, no browser tabs, no distractions.

Everything you need. Nothing between you and the words.

01 / FOCUS

Terminal-native

A responsive Ratatui interface with keyboard-first controls, designed to keep your hands on the keys.

02 / SIGNAL

Meaningful metrics

See correct WPM, raw speed, accuracy, and a per-second consistency measure after each run.

03 / MEMORY

Local history

Finished tests are stored as plain JSONL on your machine, with personal bests and an in-app history chart.

// one command away

Start typing.

Requires Rust 1.85 or newer. Install directly from the cloned repository, then launch ttype.

$ git clone https://github.com/ParthibanPillay/Ttype.git
$ cd Ttype
$ cargo install --path .
$ ttype
