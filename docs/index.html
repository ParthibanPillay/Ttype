Find your flow in the terminal.

A Monkeytype-style typing test for people who live at a prompt. Local only: no accounts, no server.

features

  • 6 modes — 15s, 30s, 60s and 10, 25, 50 words
  • 4 metrics — wpm, raw, accuracy, consistency
  • local history — plain JSONL, personal bests, in-app chart

install rust

Needs Rust 1.85 or newer. Skip this if you already have it. On Windows, also install the "Desktop development with C++" workload from Visual Studio Build Tools.

$ sudo apt update
$ sudo apt install -y git build-essential rustup
$ rustup default stable

install ttype

$ git clone https://github.com/ParthibanPillay/Ttype.git
$ cd Ttype
$ cargo install --path .
$ ttype
ttype — type with intent.
